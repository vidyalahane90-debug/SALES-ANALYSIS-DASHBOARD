# Sales Analysis Dashboard – Power BI

## Project Overview

This project focuses on analyzing sales order data using Microsoft Power BI to understand sales performance, profitability, customers, products, shipping methods, discounts, and regional performance.

## Objective

The objective of this project is to provide meaningful insights into sales performance and support data-driven decision-making.

## Dataset

The dataset contains sales transaction information including:

* Order Date
* Ship Date
* Ship Mode
* Customer ID
* Customer Name
* Segment
* City
* State
* Region
* Product ID
* Category
* Sub-Category
* Product Name
* Sales
* Quantity
* Discount
* Profit

## Tools & Technologies

* Microsoft Power BI
* Microsoft Excel
* Power Query
* Data Visualization

## Analysis Performed

### Sales Performance

* Total sales analysis
* Profit analysis
* Sales trends over time
* Regional sales performance

### Customer Analysis

* Customer purchasing behavior
* Customer segments
* High-value customers

### Product Analysis

* Category performance
* Sub-category performance
* Top and bottom-performing products

### Operational Analysis

* Shipping mode analysis
* Sales and profit by shipping method

### Discount & Profitability

* Discount analysis
* Relationship between discount and profit
* Profitability analysis
